# 設計與資料邊界

- Version：0.1.0-candidate
- Last Update：2026-10-31
- Purpose：設計與資料邊界

公開範本包含通用流程、工具及虛構樣本；私人工作目錄保存使用者自己的正式資料、穩定指標與候選。日誌與備份應保存在公開範本外。

文件編輯日期、來源日期與查證日期分別記錄。金融價格、設備狀態等易變資訊每次使用前需重新查證。候選與交接都不是即時狀態證明。

工具檢查結構、metadata、Markdown 相對連結與少量高風險字樣。它不能判斷全部個資、授權或秘密，也不會強制 agent 的操作流程。

第一版不包含 HA 控制、投資查價、服務更新或排程；這些可在獨立選用範例中逐步加入。
